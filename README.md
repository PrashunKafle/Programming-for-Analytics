# Programming for Analytics  
Focused on using Python for real-world data analysis, visualization, and decision-making.

In CIS 372 – Programming for Analytics, I developed practical skills in applying Python to data analysis and decision-making tasks. The course emphasized working with libraries such as pandas, NumPy, and matplotlib to clean, analyze, and visualize data. Through hands-on assignments and two major projects, I converted raw data into clear, meaningful insights presented through well-structured Jupyter Notebooks.

I completed the course with a strong mastery of analytical thinking, data wrangling, and effective communication of results, earning full marks for the class.
